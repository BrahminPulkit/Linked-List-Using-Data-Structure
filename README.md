# Linked Lists and Merge Sort in Java

Java data-structure and algorithm exercises.

| File | Focus |
| --- | --- |
| `LinkedListUsingNode.java` | Node-based linked-list practice |
| `MergeSort.java` | Merge-sort practice |

Use a local JDK and compile the examples with `javac *.java`. Review each source
file for its entry point and sample inputs. This is a learning repository.
